# Exhibition Company Website - Early Graduation Project Prototype

Ранний full-stack прототип веб-приложения, разработанный как первоначальный вариант будущей выпускной квалификационной работы.

Проект создавался как корпоративный сайт компании, работающей в выставочной сфере. Основной задачей прототипа было построение архитектуры веб-приложения с отдельными frontend и backend частями, REST API, системой управления контентом и обработкой клиентских заявок.

В дальнейшем от данной реализации и выбранного технологического подхода было решено отказаться, поэтому репозиторий сохранен как **архивный прототип и один из ранних этапов разработки дипломного проекта**.

> **Статус проекта:** разработка остановлена. Репозиторий хранится как ранняя версия и демонстрация первоначальной архитектуры проекта.

---

## Основная идея

Приложение разрабатывалось как корпоративный веб-сайт выставочной компании.

В рамках прототипа были реализованы:

- раздел с информацией о компании;
- список партнеров;
- отзывы клиентов;
- сертификаты и награды;
- контактная информация;
- интеграция с Яндекс Картами;
- форма отправки заявки;
- хранение заявок в базе данных;
- изменение статуса заявок через административную панель;
- управление контентом через Django Admin;
- REST API между frontend и backend;
- отдельное клиентское приложение на React.

# Архитектура

Проект построен по принципу разделения frontend и backend:

```text
                        User
                          |
                          v
                 React Application
                  TypeScript + Vite
                          |
                          |
                       Axios
                          |
                          v
                    REST API
                          |
                          v
               Django REST Framework
                          |
              +-----------+-----------+
              |                       |
              v                       v
         Django ORM              Django Admin
              |                       |
              v                       v
           Database              Content and
                              Request Management
```

Frontend отвечает за пользовательский интерфейс и взаимодействие с API.

Backend отвечает за:

- бизнес-логику;
- хранение данных;
- работу с изображениями;
- REST API;
- прием заявок;
- административное управление содержимым сайта.

# Модель данных

В прототипе реализовано несколько основных сущностей.

## AboutUs

Хранит информацию для страницы о компании:

```text
AboutUs
├── title
├── content
└── image
```

Через API клиент получает первую доступную запись и отображает ее на странице компании.

---

## Partner

Представляет клиента или партнера компании.

```text
Partner
├── name
├── logo
├── website
├── description
├── is_active
├── created_at
└── updated_at
```

Поле `is_active` позволяет управлять отображением партнера на сайте без удаления записи из базы данных.

---

## Testimonial

```text

├── created_at
└── updated_at
```

На клиентской стороне отображаются:

- изображение письма;
- текст отзыва.

## Certificate

# Интеграция с Яндекс Картами

Страница контактов содержит интерактивную карту.

Координаты передаются с backend:

```text

map_longitude
map_zoom
```

Frontend загружает Yandex Maps API и создает карту с маркером офиса.

Схема взаимодействия:

```text
Django Admin
     |
     | coordinates
     v
  Database
     |
     v
 REST API
     |
     v
React Contacts Page
     |
     v
Yandex Maps API
     |
     v
Interactive Map
```

Это позволяет изменять расположение офиса через backend без редактирования frontend-кода.

# Запуск backend

Перейти в директорию:

```bash
cd backend
```

Создать virtual environment:

```bash
python -m venv .venv
```

Активировать его.

Linux/macOS:

```bash
source .venv/bin/activate
```

Windows:

```bash
.venv\Scripts\activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Выполнить migrations:

```bash
python manage.py migrate
```

При необходимости создать администратора:

```bash
python manage.py createsuperuser
```

Запустить development server:

```bash
python manage.py runserver
```

Backend будет доступен по адресу:

```text
http://127.0.0.1:8000/
```

Django Admin:

```text
http://127.0.0.1:8000/admin/
```

---

# Запуск frontend

Перейти в директорию:

```bash
cd frontend
```

Установить зависимости:

```bash
npm install
```

Запустить development server:

```bash
npm run dev
```

Vite выведет адрес клиентского приложения, обычно:

```text
http://localhost:5173/
```

Frontend настроен на взаимодействие с backend, работающим на:

```text
http://localhost:8000
```

# Ограничения прототипа

Проект разрабатывался как экспериментальная первоначальная версия, поэтому текущая реализация не предназначена для production deployment.

В частности:

- используется development-конфигурация Django;
- `DEBUG` включен;
- текущая конфигурация базы данных использует SQLite;
- некоторые маршруты frontend являются заглушками;
- production-конфигурация окружения не завершена;
- тестовое покрытие практически отсутствует;
- конфигурация frontend/backend требует дополнительной подготовки для production-среды.
